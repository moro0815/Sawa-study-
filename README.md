# 🐾 さわの勉強部屋 — AI家庭教師

中学1年生のためのAI家庭教師アプリです。将来の夢「獣医さん」を目指して、楽しみながら全教科を勉強できます。

## ✨ できること

| 機能 | 説明 |
|---|---|
| 🐰 ミミ先生とチャット | わからないことを何でも質問できます。答えをすぐ教えず、ヒントで導く「一緒に考える」教え方です |
| 📷 宿題・問題集の写真アップ | 問題集や宿題をスマホのカメラで撮って送ると、ミミ先生が読み取って1問ずつ一緒に解いてくれます |
| 📚 全教科対応 | 国語・数学・英語・理科・社会・音楽・美術・保健体育・技術家庭 |
| 🎯 クイズモード | ボタン1つでその教科のクイズに挑戦。正解するとXPがもらえます |
| ⭐ XP・レベルシステム | 勉強するとXPがたまり、「どうぶつ見習い」から「獣医師」までレベルアップ |
| 🔥 連続学習記録 | 毎日続けるとストリークが伸びてやる気アップ |
| 📋 デイリーミッション | 「質問を3回する」「宿題を写真で送る」など毎日の小さな目標 |
| 🦁 どうぶつ図鑑 | XPがたまるごとに動物が仲間に。全32種類+動物の豆知識つき |

## 🚀 セットアップ(おうちの人向け・約10分)

### 1. Claude APIキーを取得する

1. [console.anthropic.com](https://console.anthropic.com/) にアクセスしてアカウントを作成
2. 支払い方法を登録(クレジットカード。従量課金です)
3. 「API Keys」→「Create Key」でキーを作成し、`sk-ant-api03-...` で始まる文字列をコピー

> 💰 **料金の目安**: 1回の質問で数円〜十数円程度です。使いすぎが心配な場合は、Anthropicコンソールの「Limits」で月あたりの利用上限を設定できます。

### 2. アプリを開く

**方法A: そのままファイルを開く(いちばん簡単)**

このリポジトリをダウンロード(緑の「Code」ボタン →「Download ZIP」)して展開し、`index.html` をブラウザ(Chrome / Safari / Edge)で開くだけで使えます。

**方法B: GitHub Pagesで公開してスマホから使う(おすすめ)**

宿題の写真を撮るならスマホ・タブレットが便利です。

1. このリポジトリの「Settings」→「Pages」を開く
2. 「Source」を `Deploy from a branch`、Branchを `main` / `(root)` にして保存
3. 数分後に表示されるURL(`https://ユーザー名.github.io/Sawa-study-/`)にスマホからアクセス
4. ホーム画面に追加すればアプリのように使えます

> ⚠️ **重要**: このリポジトリを **Private(非公開)にすることをおすすめします**。GitHub PagesのURLも家族以外に教えないでください。APIキー自体はページには含まれず、各端末のブラウザ内にのみ保存されますが、URLを知っている人は誰でもページ自体を開けるためです。

### 3. アプリ内でAPIキーを設定

初回起動時に「せってい」画面が開きます。

1. コピーしたAPIキーを貼り付け
2. お子さんの名前を入力(ミミ先生がその名前で呼びかけます)
3. 「保存する」をタップ

これで完了です!「べんきょう」タブから始められます。

## 📱 使い方(お子さん向け)

- **質問する**: 「べんきょう」タブで教科を選んで、わからないことを送ってみよう
- **宿題を撮る**: 📷ボタンで問題集や宿題の写真を撮って送ると、ミミ先生が一緒に解いてくれるよ
- **クイズ**: 「🎯クイズに挑戦」ボタンで力だめし。正解するとXPゲット!
- **毎日続ける**: 連続で勉強すると🔥ストリークが伸びるよ。ミッションもクリアしよう
- **ずかん**: XPがたまると新しいどうぶつが仲間になるよ。全部集めて獣医さんに近づこう!

## 🔒 プライバシーとデータについて

- 会話・XP・図鑑などのデータはすべて**お使いの端末のブラウザ内(localStorage)にのみ保存**されます。外部サーバーには保存されません
- APIキーも端末内にのみ保存されます
- 質問内容と写真は回答生成のためにAnthropicのAPIに送信されます(Anthropicの[プライバシーポリシー](https://www.anthropic.com/legal/privacy)が適用されます)
- ブラウザのデータを消去するとアプリのデータも消えます。別の端末とはデータ共有されません

## 🛠 技術構成

- 純粋なHTML / CSS / JavaScript(ビルド不要・サーバー不要)
- [Claude API](https://platform.claude.com/)(モデル: `claude-opus-5`)をブラウザから直接呼び出し
- 写真は端末内でリサイズ(長辺1568px・JPEG)してから送信し、通信量とコストを節約
- プロンプトキャッシュを利用してAPIコストを削減
