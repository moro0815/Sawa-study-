# 🩺 沙和ナビ

中学1年から大学受験まで、6年間伴走するAI学習システム。
世界の学習科学の研究を検証し、**効果が確認されている手法だけ**で組み立てています。

**夢は変数です。** このアプリは今の志望を全力で応援しますが、それを固定しません。
**学年に応じて姿を変えます。** 中1に受験の話は見せません。見た目も、その時々で気持ちが上がるものを選べます。

→ [科学的根拠と出典の全リスト](docs/EVIDENCE.md)

---

## ふつうの学習アプリと違うところ

### 1. つまずきの「本当の原因」を過去にさかのぼって特定する

一次関数ができないとき、多くのアプリは一次関数を教え直します。
このシステムは違います。中1〜高3の**全教科210概念を前提関係のグラフ(DAG)**で保持し、土台をさかのぼります。

```
一次関数 (中2) が解けない
   ↑ が土台
比例 (中1) — 習得30%
   ↑ が土台
一次式の計算 (中1) — 習得55%
   ↑ が土台
正負の数の乗除 (中1) — 習得20%  ← 🚨 本当の原因はここ
```

原因を直してから戻ると、上の単元が一気に通ります。優秀な家庭教師がやることを、システムとして実装しました。

### 2. 「わかったつもり」を最優先の弱点として扱う

答える前に**必ず確信度を申告**させます(◎自信ある / ○たぶん / △わからない)。
確信度 × 正誤で4象限に分け、**「自信あり×不正解」を最優先**にします。

| | 正解 | 不正解 |
|---|---|---|
| **自信あり** | ✅ 定着 | 🚨 **わかったつもり(最優先)** |
| **自信なし** | 🌱 自信不足 | 📘 未習得 |

逆説的ですが、**自信を持って間違えた場所こそ最も強く・長く修正されます**(ハイパーコレクション効果)。
ただし研究では「1週間後に誤りが復活する」ことも判明しているため、**訂正した直後に再出題し、さらに12時間後の再テストを強制的に予約**します。

「わかったつもり率」として数字でも可視化します。この数字が高いほど、本番で崩れやすい状態です。

### 3. わざと混ぜて出題し、その理由を本人に説明する

問題は必ず単元をまたいで混ぜます(交互練習)。研究ではテスト成績が約2倍になります。
**ただし練習中の正答率は 89% → 60% に下がります。**「できていない感じ」がするので、多くの生徒はここでやめてしまいます。

そこでこのアプリは、**「今わざと混ぜている。今日できないのは設計どおり」と本人に明示**し、
「練習中の正答率」と「定着度」を別メーターで表示して混同を防ぎます。
保護者レポートにも同じ説明を載せ、正答率の低さで叱られないようにしています。

### 4. 3つの人格 — 先生・相棒・伴走者

自己決定理論の3つの欲求(有能感・関係性・自律性)にそれぞれ対応させています。

| | 役割 | 支える欲求 | やること |
|---|---|---|---|
| 🐰 **ミミ先生** | 先生 | 有能感 | 答えを言わず導く。確信度を聞き、前提をさかのぼる |
| 🐾 **Luke** | 相棒(沙和さんの犬)| 関係性 | 評価しない。**沙和さんが教える側に回る**(プロテジェ効果) |
| 🦉 **ナギ** | 伴走者 | 自律性 | 計画・振り返り・テスト不安。**必ず選択肢を出し、本人が決める** |

**自分で選んだ相手からは、勝手に離れません。**

「しんどい」と打てばLukeに、「計画を立てたい」と打てばナギに切り替わりますが、これは**まだ誰も選んでいないとき**だけです。
自分でLukeを選んだあとは、何を話しても**Lukeのまま**です。

> 唯一の例外は「つらそうな合図」で、このときだけはLukeへ動きます。**慰めのほうへしか動かない**ようにしてあります。
> 相手が勝手に変わってしまうと、話しかけている実感そのものが壊れます。最適化より、選んだ相手のままでいられることを優先しました。

### 5. 相棒の犬 Luke — 反応するけれど、できなかったことでは離れない

沙和さんの犬 **Luke(マルプー・男の子・アプリコット)** が、勉強のとなりにいます。
**実物の写真を見て描き起こしました** — 赤みのあるアプリコットの巻き毛、あごより下まで垂れる波打った耳、
ライムイエローの首輪。輪郭は円を重ねるのではなく、こぶを並べた曲線で作っているので、巻き毛らしく見えます。

**絵は自分で用意したものに差しかえられます。** ChatGPT などで作ったイラストをそのままLukeにできます。
初期状態ではコードで描いた絵(SVG)が出ますが、**画像を1枚入れるだけで、全部その絵になります。**

| | 初期の絵(SVG) | 自分で入れた絵 |
|---|---|---|
| 用意 | 不要 | 画像を1〜6枚 |
| オフライン | ○ | ○(端末内に保存) |
| 拡大しても粗くならない | ○ | 元の画像しだい |
| 耳・しっぽ・舌が動く | ○ | 上下のはずみ・首のかたむきのみ |
| かわいさ | ほどほど | **好きなだけ** |

**入れ方**:ホーム → Lukeのカード →「Lukeのこと」→「**Lukeの絵を変える**」→ 枠をタップして画像を選ぶだけ。
きもちは6枠(ふつう / うれしい / きょとん / びっくり / ソッポ / おやすみ)ありますが、
**「ふつう」の1枚を入れれば残りもその絵になります。**

**選んだあと、その場で切り抜けます。** 写真をそのまま入れると床や部屋まで写ってしまうので、
ドラッグで位置、スライダーで大きさを合わせて、**顔だけ**を切り出せるようにしました。
写真アプリでトリミングしてから来る必要はありません。

**「↻ 回す」もつけました。** iPhoneの写真は、向きの情報(EXIF)の扱いが端末や経路でまちまちで、
横向きのまま出ることがあります。自動判定に頼らず、その場で90度ずつ回せるほうが確実です。

**写真は自動で丸く抜きます。** 切り抜いた画像に透明な部分がなければ「写真」と判断し、円形で表示します。
背景の残りが目立たなくなり、アイコンとして収まります。
透明なPNG(キャラクターのイラストなど)は、そのままの形で出します。**判定は自動です。**

- 画像は**この端末の中だけ**に保存されます。どこにも送信されません
- 一辺300pxに縮めて持つので、6枚入れても**数十KB**です
- **機種変更しても消えません** — ファイル書き出しとサーバー自動バックアップに含まれます
  (端末内の12世代のひかえには入れていません。容量を食いつぶさないためです)

| 何があったか | Luke |
|---|---|
| できた | しっぽが止まらない。跳ねる |
| **まちがえた** | **きょとん。首をかしげるだけ**。がっかりしない |
| **自信あったのに間違えた** | **目をまんまるにして、いちばん喜ぶ**「たからもの見つけた!」 |
| 「答え教えて」と言った | **ぷいっとソッポ**。「…教えないもん」 |
| 確信度を言わずに答えた | 同じくソッポ。「先に言って?」 |
| つらいと言った | 何も言わずにすりよる |
| 何日も会えていない | しょんぼり。でも戻った瞬間に大喜び |
| 夜おそい・長時間やった | ねむそうに「そろそろ休も?」 |

#### 「まちがえたらソッポを向く」を、そのままにはしませんでした

反応が返ってくるのは楽しい機能です。ただ**【間違い】に対してそっけなくする作りは、このアプリでは使えません。**理由が3つあります。

1. このシステムの中核は「自信あり×不正解」を最優先で拾うこと(#2)。**間違いを見せた瞬間に相棒が離れると、間違いを隠すようになります。**いちばん伸びる場所が、いちばん見えなくなります
2. 沙和さんは、わからないことを人に聞くのが少し苦手。「できないと嫌われる」の形は、この子にはいちばん強く効いてしまいます
3. 愛情を成績の条件にすること(条件つき肯定)は、保護者向けの説明で「やめてください」と書いていること そのものです

そこで **ソッポは残して、向ける相手を変えました。**

> **Luke がそっぽを向くのは「できなかったとき」ではなく「近道をしようとしたとき」です。しかも、すぐ許します。**

答えを聞こうとしたとき、確信度を飛ばしたとき。この2つだけです。**「ちゃんとやらないとLukeが悲しむよ」という使い方はAIにも禁じています。**

#### 成長を2つに分けました

| | 何で育つか | なぜ |
|---|---|---|
| **年齢** | **実際の時間**。何をしてもしなくても育つ | 犬の愛情は条件つきではないからです |
| **できる芸** | 一緒にやったことの**中身** | 何をしたかが残るように |

Luke はいま1歳。沙和さんが高3になるころには**7歳の大人の犬**になります。人でいうと約44歳 — 犬は先に大人になります。獣医を目指す子にとって、これは知っておいて損のない事実でもあるので、**「人でいうと約◯歳」も出しています**。誕生日を入れると、その日にお祝いします。

**芸が増える条件は、ぜんぶ「良い学び方ができたか」です。正解の数ではありません。**

| 芸 | 覚える条件 |
|---|---|
| 🐾 おて | 答える前に「どのくらい自信あるか」を1回言えた |
| ⏳ まて | 3日つづけて勉強した |
| 🙋 ふせ | **「わからない」と1回言えた** |
| 🔁 おかわり | まちがえた問題を直して、もう1問やった |
| 🙌 ハイタッチ | 「自信あったのに間違えた」を1つ直した |
| 🌀 おまわり | ちがう教科を混ぜて解いた |
| 🗣 はなす | Lukeに1回、説明してあげた |
| 🧭 みちあんない | 自分から勉強を始めた日が5回 |

ごほうびとしてぶら下げません(#7 の理由です)。**あとから「そういえば覚えたね」と気づく形**にしてあります。

#### Luke は「教わる側」です

Luke は相棒の人格そのものでもあります(#4)。まだ子犬で勉強のことは何も知らないので、**沙和さんが教える側に回ります**(プロテジェ効果)。わざと少し的外れな質問をして、説明させます。同い年の友だちより、1歳の犬のほうがこの役はずっと自然に成立します。

### 6. 送ったものを、取り消せる

写真を送りまちがえた。聞き方をまちがえた。返事が長くて止めたい。**そのどれも取り消せます。**

| | いつ | 何が起きるか |
|---|---|---|
| **送信をやめる** | 送信中(ボタンが■に変わっている間)| 通信を止め、**書いた文と写真が入力欄に戻る**。エラー扱いにしない |
| **直前のやりとりを取り消す** | 送ったあと | 自分の発言とAIの返事を、会話から消す |
| 写真を1枚ずつ外す | 送る前 | プレビューの ✕ |

**送信をやめる**は、通信そのものを中断します(`AbortController`)。押した時点で課金も止まります。
返事が長くなりそうなとき、送る相手をまちがえたとき、12秒待つ前に止められます。
**やめても失敗の扱いにはしません。** 書いた内容と写真がそのまま戻るので、直してすぐ送り直せます。

**直前のやりとりを取り消す**で消えるのは**会話だけ**です。

> ⚠️ **記録した宿題や答えの記録は消しません。** 一緒に消すと、正しく記録されたものまで巻き添えになるからです。
> 宿題を登録しまちがえたときは、宿題カードから個別に消してください。

取り消しは**AIに送る履歴からも消える**ので、次の送信からその分の料金もかかりません。
会話の途中がおかしくなっても、`tool_use` と `tool_result` の対応は自動で整えます。

### 7. ポイントで釣らない

外的報酬は、報酬がなくなった瞬間にやる気を以前より下げます(過正当化効果)。
そのためXP・バッジ・レベルを主軸から外し、代わりに**「どの概念が本当にできるようになったか」と「夢との距離」**を表示します。

### 8. 中1に受験の話を見せない — 学年で姿が変わる

**中学1年生に「大学受験まであと1988日」と毎日見せることには、害があります。**

| 研究 | 何がわかっているか |
|---|---|
| Lancet Child & Adolescent Health (2025) | 中等教育期の学業プレッシャーの高さは、**抑うつ症状と自傷のリスクを高め、成人期初期まで持続しうる** |
| 52研究のレビュー | 学業プレッシャーと不安・抑うつ・自殺念慮の正の関連が大半で確認 |
| Frontiers in Psychology (2022) | プレッシャーは**自律性を損ない、内発的動機を「統制された動機」に置き換える** — 成績を上げるどころか下げる |

そこで、**学年ごとに見せるものを変えます。**

| 学年 | 段階 | 大学受験の<br>カウントダウン | 模試 | 併願戦略 | 学費 | 共通テスト |
|---|---|:-:|:-:|:-:|:-:|:-:|
| 中1・中2 | たねまき期 / 根をはる期 | ✕ | ✕ | ✕ | ✕ | ✕ |
| 中3 | はじめての受験 | ✕ | ○ | ✕ | ✕ | ✕ |
| 高1 | つみあげ期 | ✕ | ○ | ✕ | ○ | ○ |
| 高2・高3 | しぼりこみ期 / しあげ期 | ○ | ○ | ○ | ○ | ○ |

中学生のうちは、トップバーの「要注意」カウンタも出しません。保護者への共有リンクにも受験の残り日数を含めません。

#### 締切の代わりに使うもの — 未来の自分とのつながり

Hershfield らの研究では、いまの自分と未来の自分が心理的につながっていると感じられるほど**長期的な行動を取りやすく**、思春期ではつまずきを「自分を決定づけるもの」ではなく「**一時的で扱えるもの**」と解釈できることが示されています。

- **未来の自分への手紙(タイムカプセル)** — 1年後・3年後などに届く手紙を書けます。書いた手紙は時が来ると自動で開きます
- **ここまでの道のり** — 一緒に過ごした日数と、7日・1ヶ月・100日・1年…6年の節目

### 9. 見た目が、その時々で変わる

中学生と高校生では好みが変わります。**6つのテーマ**を用意し、学年に応じて自動で選ばれますが、**本人がいつでも変えられます**(選べること自体が自律性の支援になります)。

| テーマ | 想定学年 | |
|---|---|---|
| 🌱 ふたば | 中1〜中2 | やわらかくて、あたたかい |
| ☁️ そら | 中3 | 明るくて、まっすぐ |
| 🌿 ミント | 高1 | すっきりして、集中しやすい |
| 🖋 すみ | 高2〜高3 | 落ち着いて、余計なものがない |
| 🫐 ベリー | いつでも | かわいくて、元気が出る |
| 🌙 よる | いつでも | 暗い部屋でも目が疲れない(ダークモード) |

角の丸み・書体・配色がすべて切り替わります。中1のまるい書体から、高3のミニマルな画面まで、6年かけて一緒に育ちます。

### 10. 夢は変わる。だから固定しない

**これは設計上いちばん重要な判断でした。**

ひとつの職業を前提にアプリを作ると、実は発達心理学上の害があります。

| 研究 | 何がわかっているか |
|---|---|
| **早期完了**(Marcia) | 探索を経ずに早く決めた状態は、**周囲が肯定し続けている間は安定して見えるが、その支えが崩れた瞬間にもろくなる** |
| **囲い込み**(Gottfredson) | 子どもは9〜13歳にかけて職業の選択肢を次々に**消していく**。内面的な自己で選び直せるのは14歳以降 |
| **計画された偶発性**(Krumboltz) | キャリアの大半は予期しない出来事で決まる。「**迷っていること自体が望ましく理にかなっている**」 |
| **縦断研究** | 思春期の**約3分の1**が志望を大きく変え、**約20%**は「決まっていない」状態にある |

つまり、**アプリが毎日「獣医さんになるんだよね」と肯定し続けること自体が、その「支え」になってしまう**のです。

#### だからこう作りました

- **志望は変数**。19の進路(動物・医療から法律・デザイン・情報まで)からいつでも変更できます
- **「まだ決めていない」を正式な選択肢に**。欠点ではなく健全な探索期として扱います
- **過去の夢は消さずに残します**。変わったことは失敗ではなく成長です
- **AIは絶対に引き止めません**。「本当にそれでいいの?」と疑いを差し込むことを禁じています
- **伴走者(ナギ)は探索を促します**。「動物のどんなところが好き?」「動物以外で時間を忘れることは?」

#### 「今までの勉強が無駄になる」を数字で否定する

志望を変えるときいちばん大きい不安がこれです。実際には無駄になりません。アプリが計算します。

```
獣医師を目指して積み上げた学習が、他の道でどれだけ活きるか

  医師              98%
  生命科学の研究者   97%
  バイオ・製薬企業   97%
  薬剤師            92%
  エンジニア・情報   90%
  農学・畜産         89%
  …
  デザイン・芸術     46%   ← 最も遠い道でも半分近くは残る
```

転用率が低いときも数字は正直に出します。そのうえで「**わからないことを分解して考える力、間違いから直す力は教科に関係なく残る**」と伝えます。嘘はつきません。

**志望を変えると、学習の優先順位も自動で変わります。**

```
獣医志望 : 数学 > 理科 > 英語 > 社会 > 国語
法律志望 : 社会 > 国語 > 英語 > 数学 > 理科
```

迷っている時期のために「**どの道でも効く教科**」も出します(理科84 / 英語83 / 数学78 …)。決めていない間は、上位の教科を厚くしておくのが最善の戦略です。

### 11. 学校の宿題を取り込み、AI家庭教師も宿題を出す

**宿題は2系統あります。**

| | 出どころ | 取り込み方 |
|---|---|---|
| 📚 **学校** | 学校から出たもの。**最優先** | iPhoneのカメラ / 書類スキャンで取り込む |
| 🤖 **AI先生** | 弱点と復習期限から自動で組む | ホームのボタン、または会話で頼む |

**取り込みは2つの経路を分けています。**

- **📷 カメラ** — その場で1枚。`capture="environment"` で背面カメラが直接開きます
- **📄 スキャン** — iPhoneの「書類スキャン」で撮ったものを**複数ページまとめて**送れます。PDFのまま送ることもできます(Gemini・Claude)

> 💡 **精度が段違いなのはスキャンです。** iOSの書類スキャンは、斜め・ゆがみを自動でまっすぐに直し、影を飛ばします。手で持って撮った写真よりずっと正確に読み取れます。アプリ内に「やり方」ボタンを置き、メモアプリ / ファイルアプリでの手順を案内しています。

**AIが出す問題の難しさは「85%ルール」で自動調整します。**

Wilson et al. (2019, *Nature Communications*) — 学習が最も速く進むのは**正答率が約85%**のとき。易しすぎても難しすぎても伸びが鈍ります。

```
直近の正答率 100%  → 易しすぎ。次は一段難しく
直近の正答率  88%  → ちょうどよい。この難しさを保つ
直近の正答率  38%  → 難しすぎ。一段易しくするか、前提の確認から
```

**量は「学校のぶんを引いた残り」にしか入れません。**

```
1日の目安 40分
  − 学校の宿題(4問 × 3分)= 12分
  − すでに出したAIの宿題    =  5分
  ────────────────────────────
  残り 23分ぶんだけ出題可能   ← 5分を切ったら「今日は学校のぶんで十分」
```

中身は**復習を約2/3・新規を約1/3**、単元は必ず混ぜます(交互練習)。新しい概念の1問目は解答例つきから入り、慣れるにつれて例を減らします(ワークトエグザンプルのフェーディング)。

**「わからない」は片づけません。** 1問ごとに「わからない」と印をつけられ、その問題は**終わった扱いにしません**。印がついた問題は最優先で、前提までさかのぼって説明します。保護者にも「隠さずに言えたのは良い兆候」として伝えます。

### 12. 模試の偏差値を「大学の基準」に換算する

**ここは家庭が最も判断を誤るところです。** 同じ実力でも、受ける模試によって偏差値は10〜15変わります。母集団が違うためです。

| 模試 | 特徴 |
|---|---|
| 進研模試(ベネッセ) | 学年ほぼ全員(約45万人)。大学進学しない生徒も含む → **最も高く出る** |
| 全統模試(河合塾) | 大学受験生が中心 → **大学の偏差値表はこれが基準** |
| 駿台全国模試 | 難関大志望者中心 → **最も低く出る** |

実際にこのアプリで検証した例です:

```
進研模試 偏差値60 をそのまま使う  → 北海道大学 獣医学部は「射程圏」
正しく河合塾基準に換算(約50)    → 実際は「挑戦圏」
```

**判定が2段階ずれます。** アプリは模試の種類を選ばせ、自動で河合塾基準に換算してから志望校との距離を出します。高校受験の偏差値は母集団がまったく違うため、換算せずに警告を出します。

### 13. 大学受験まで、日数で見える(高2から)

- 共通テストまでの**カウントダウン**(残り日数・週末の回数)※高2以降のみ表示
- **逆算マイルストーン** — 「高2の3月までに受験科目のインプットを完了」「高1の秋までにmol計算を確実に」など、いつまでに何が終わっていれば間に合うか
- **入試方式は3つ** — 一般選抜だけでなく、学校推薦型・総合型。推薦は**高1の1学期から評定平均が対象**になるため、中学のうちから知っておく意味があります
- **併願戦略** — 獣医学部は17校しかないため、挑戦圏・射程圏・安全圏の組み合わせを自動で提案
- **受験イヤーの年間スケジュール** — 模試・出願・本番の流れ
- **費用の見通し** — 獣医学部は6年制。国公立 約365万円 に対し私立は約1,180〜1,400万円で**3〜4倍**違います。早く知るほど進路の選び方が変わります

### 14. 成績を入力すると、次にどこへ時間を使うべきか出る

- **定期テスト**:点数と平均点から相対的な立ち位置と推定偏差値を算出
- **内申点**:9教科×5段階=45点(2021年度からの3観点評価に対応)
- **模試偏差値**:模試の種類を換算したうえで獣医学部**全17校**との距離を自動計算
- **高校の評定平均値**:学校推薦型選抜の出願資格(多くが3.8〜4.3以上)を判定
- **限界効用分析**:習得度の穴・テストの得点・獣医学部での重要度を合成し、**同じ1時間を投じて最も合格可能性が上がる教科**を順位づけ

### 15. パソコンでは画面全体を使う。ただし本文は伸ばさない

スマホとパソコンでレイアウトを変えます。**空いた横幅は「1行を長くする」のではなく「カードを横に並べる」ことに使います。**

1行が長くなりすぎると読み返しの負担が増え、行を見失いやすくなります(日本語で読みやすいのは1行あたりおよそ30〜40字)。全幅に本文を引き伸ばすのは、画面は埋まっても読みにくくなるだけです。

| 画面幅 | タブ | カード | チャット |
|---|---|---|---|
| 〜899px(スマホ) | 下の帯 | 1列 | 画面高の58%まで |
| 900〜1439px | **左の縦メニュー** | **2列** | 幅900pxで縦いっぱい |
| 1440〜1899px | 左の縦メニュー | **3列** | 幅980pxで縦いっぱい |
| 1900px〜 | 左の縦メニュー | **4列** | 同上 |

- カード1枚の幅は、どの段数でもおよそ400px(日本語で約33字)に保たれます
- **横に長いほうが見やすいものだけ全幅**にします — ホームのあいさつ、宿題、知識マップ、獣医学部一覧、テーマ選択
- 全幅にしたカードの中身はさらに横に並べます(宿題は2〜3件が横並び)
- チャットは幅を広げず、代わりに**縦を画面いっぱい**に使います
- 保護者への共有リンク(share.html)もパソコンでは2列になります

### 16. 記録が消えないように、自動で守る

学習記録が消えたら6年ぶんの積み上げが失われます。**基本は全自動**にしました。

| | 何をするか | いつ | 端末が壊れても残る? |
|---|---|---|---|
| 1️⃣ **サーバーへ自動保存** | 契約中のサーバーに預ける | **30分に1回・全自動** | ✅ **残る** |
| 2️⃣ 端末内のひかえ | その日の状態を保存(最大12件) | 5分ごとに自動 | ✕ |
| 3️⃣ 消す前のひかえ | 「すべて消す」の直前に保存 | 自動 | ✕ |
| 4️⃣ ファイル書き出し | iCloud Drive等に保存 | 手動 | ✅ |

**1️⃣ が本命です。** `api/backup.php` を他のファイルと一緒に置き、アプリで**ボタンを1回押すだけ**。以後は何もしなくても自動で預かります。

```
public_html/
├── api/backup.php     ← 置くだけ。書き換え不要
└── …
（1つ上の階層）
└── sawa-backups/      ← 記録はここ。ブラウザからは開けない
    ├── token.txt      ← 合言葉(自動生成)
    └── bk-*.json      ← 最新30世代
```

- **保存先は `public_html` の外**なので、URLを知られても中身は取り出せません
- 書き込みには**合言葉**が要ります。初回にサーバー側が自動生成し、その1回だけアプリに渡します(2回目以降は拒否)
- **APIキーと合言葉はバックアップに含めません。** 端末の外に認証情報を出さないためです(戻したあとも、今の端末の設定がそのまま使われます)
- ファイル名は検証済みで、`../` などでほかのファイルを読み出せません
- **アプリを上書き更新しても、預けた記録と合言葉は消えません**

- 1️⃣ は**その日のぶんを上書き更新**します。起動時に1回だけだと、その日の勉強がまるごと失われるためです
- ひかえに**会話履歴は含めません**。容量を食うわりに失っても困らないためです(記録・宿題・成績・手紙・夢の履歴は全部入ります)
- 端末の容量が足りなくなったら、古いひかえから自動で捨てます。**手動で取ったひかえは優先して残します**
- 前回のファイル書き出しから30日たつと、保護者タブに色つきでお知らせが出ます
- 読み込みは新旧どちらの形式でも受け付けます

### 17. 保護者は状況を確認できる。ただし「監視」ではなく「支援」として

研究では、統制的な関わり(命令・監視・比較)は意欲を確実に下げ、自律性支援(理由の説明・気持ちの承認・選択肢)は成績と心理的健康の両方を高めます。保護者画面はこの原則に沿って設計しています。

| 機能 | 内容 |
|---|---|
| **今週、まず知っておくこと** | 最も重要な1件だけを、解釈と**かけるとよい言葉**つきで提示 |
| **気づいたこと** | 学習の中断・成績の下落・わかったつもり率の上昇などを自動検出。**良い変化を必ず先に表示** |
| **学習の記録** | 7日/30日/90日で切替。学習日数・問題数・学習時間・新規習得数・教科別内訳 |
| **受験までの位置** | 残り日数・模試(換算後)・内申点・評定平均・射程圏の大学数 |
| **レポート書き出し** | **三者面談や離れて暮らす家族との共有**にそのまま使えるテキストを生成。コピー / .txt 保存 |
| **声のかけ方** | 避けたい言葉 / 効果がある言葉を具体例で提示 |
| **志望の状況** | 今の志望・変更回数・気になっている道。変更を否定的に解釈しません |
| **夢が変わったとき、どう反応するか** | 研究に基づく事実4件＋避けたい言葉/効果がある言葉を各6件 |
| **科学的根拠** | 全機能の出典と効果量。効果が疑わしいものは疑わしいと明記 |

アラートは**すべて「解釈」と「かける言葉」つき**です。数字だけを見せて叱る材料にしないための設計です。
検出結果には責める表現(「怠けている」等)を一切含めないことをテストで検証しています。

**学習時間の計測**:学習画面にタイマーがあり、実際の学習時間が保護者レポートに反映されます。

**夢が変わったときの声かけ** — ここは保護者が最も反射的に反応してしまう場面です。一言で探索そのものが止まります。

| ✕ 避けたい | なぜ |
|---|---|
| 「あんなに獣医って言ってたのに」 | 過去の発言で縛ると、次から本音を言わなくなります |
| 「今までの勉強、無駄になっちゃうよ」 | **事実として誤りです**。主要教科の土台はほとんどの進路で共通します |
| 「本当にそれでいいの?」 | 疑いを差し込むと、自分の判断を信じられなくなります |
| 「まだ決まってないの?」 | 迷いを欠点として扱うことになります。迷いは探索です |

| ○ 効果がある | なぜ |
|---|---|
| 「そう思ったきっかけ、聞かせて」 | 評価せずに中身を聞く。ここから対話が始まります |
| 「そう思えるようになったんだね」 | 変化そのものを成長として認める |
| 「今までの勉強はほとんどそのまま使えるよ」 | 事実です。不安を具体的に打ち消せます |
| 「決まってなくても大丈夫だよ」 | 迷える時間を保証することが、最良の支援になります |

> 親が特定の職業を望んでいると子どもが感じると、本音の探索が止まります。**「どの道でも応援する」と実際に言葉にして伝えてください。**

### 18. 「勉強のやり方」そのものを教える — 学び方タブ

問題を解かせるだけでは、**勉強が好きになりません**し、**やり方も身につきません**。ここは独立した機能として作りました。

#### ① 好奇心は「知識の穴」から生まれる — だから、教える前に穴を開ける

Loewenstein (1994) の情報ギャップ理論では、好奇心は「知らないこと」ではなく**知っていることと知りたいことの間に穴があると自覚したとき**に生まれます。Kang ら (2009) は、**好奇心が高まった状態で得た答えは記憶に残りやすい**ことを確認しています。

```
✕ 「食塩水の濃度は、溶質÷全体×100で求めます」
○ 「体重3kgの子猫に、20kgの犬と同じ濃さの薬を同じ量あげたら、どうなると思う?」
   → 予想させる → そこで初めて式に入る
```

説明の終わりにも**次の穴**を残します(「体重が2倍なら薬も2倍でいい? …これは次回」)。AIには「教える前に必ず穴を開ける」「終わりは必ず問いで閉じる」をプロンプトで課しています。

#### ② 興味は4段階で育つ。段階を判定して、やり方を変える

Hidi & Renninger (2006) の4段階モデルを**教科ごとに**推定します。判定材料は本人の記録(学習回数 / 失敗した翌日に戻ってきたか / 自分から始めたか / 自分から質問したか / 続いた日数)。

| 段階 | この段階で効くこと | 逆効果なこと |
|---|---|---|
| 1 きっかけ期 | 驚き・意外な事実・具体物から入る | 「大事だから」と価値を説く |
| 2 つながり期 | 本人の関心(動物・身近な出来事)に結びつける | 抽象的な練習だけ続ける |
| 3 自分から期 | 「なぜそうなるか」を一緒に掘る | 答えを先に渡す |
| 4 自分のもの期 | 難しい課題・人に説明する役をまかせる | 手取り足取り教える |

同じ「数学が苦手」でも、段階1と段階3では打つ手が正反対です。段階と対処法は毎回プロンプトに差し込まれます。

#### ③ 効く勉強法を、本人の記録で証明して見せる

Dunlosky ら (2013) の大規模レビューでは、**線を引く・読み返す・要約するは最低ランク**、分散学習と検索練習は最高ランクでした。厄介なのは、**低効用の方法ほど「効いている感じ」がする**ことです。だから多くの生徒が、効かない方法を自分から選び続けます。

そこで裏で適用するだけにせず、**6枚のカード**にして本人に見せます。

| カード | やりがち | かわりに |
|---|---|---|
| 思い出す練習 | 答えを見ながら読み返す | 何も見ずに思い出してから確認する |
| 間隔をあける | 前日にまとめてやる | 3日・1週間と間をあけて戻る |
| 自信を先に言う | いきなり答える | ◎○△を先に言ってから答える |
| 混ぜて解く | 同じ単元を続けて解く | わざと違う単元を混ぜる |
| 人に説明する | わかったつもりで次へ | 声に出して誰かに説明する |
| なぜを追う | 公式を覚える | なぜそうなるかを1回だけ追う |

各カードには「なぜ効くか」「出典」に加えて、**沙和さん自身の記録から計算した差**が出ます。

```
思い出す練習を3回以上した単元の定着は 88%、1回だけの単元は 35%。
3日以上かけて復習した単元は 88%、同じ日に固めた単元は 50%。
```

記録が足りないうちは差を出さず「まだ記録が足りません」と正直に表示します。**数字を作りません。**

**予想してから答え合わせをするクイズ**も5問あります。「読み返すのと思い出すの、どちらが残る?」と先に予想させてから正解を見せます。外した瞬間のほうが強く残るためです。

#### ④ 飽きさせない — 報酬ではなく「型」を変える

ポイントで釣ると逆効果になります(過正当化効果、#5)。そこで**やることの形**を8種類用意し、直近で使った型を避けて回します。

`小テスト` / `予想してから確かめる` / `まちがい探し` / `AIに教える` / `なぜを掘る` / `身のまわりで探す` / `1分スピード` / `つなげてみる`

直近3回で使った型はプロンプトに渡り、AIは**同じ型を続けません**。

#### ⑤ 「できるようになったこと」を毎週、言葉で返す

数字(習得度62%)は達成感になりません。**今週できるようになったこと**を単元名で並べます。「一次方程式の移項ができるようになった」「濃度の計算をやり直して直った」。会話の終わりにもAIが必ず一つ挙げてから、次の問いで閉じます。

### 19. AIが本当に働いているか、目で見える

「返事は来ているけれど、ちゃんとAIが動いているのか、いくらかかっているのか分からない」— ここを見えるようにしました。

**AIの返事の一つひとつの下に、実際の通信の中身が出ます。**

```
Gemini gemini-3.6-flash ・ 0.3秒 ・ ツール6回 ・ 37,520トークン ・ 約10.42円
```

- どのAI・どのモデルが答えたか(切り替えたつもりで切り替わっていない、が分かります)
- 何秒かかったか
- **ツールを何回使ったか** — ここが0なら、記録を読み書きせずに雑談で返しただけです
- トークン数と、そこから計算した**概算費用**

**待っている間も**「Gemini(gemini-3.6-flash)に聞いています…」と、どこに問い合わせているかを表示します。

**保護者タブに「AIの通信」カードがあります。**

| | |
|---|---|
| 接続を確かめる | ボタン1つで実際にAPIを叩き、往復できるか・何秒かかるかを確認 |
| 今日の使用量 | 回数・トークン・概算費用の合計 |
| 直近12件の記録 | 時刻 / モデル / 秒数 / **呼ばれたツール名**(`record_answer` `get_homework` …)/ 費用 |
| 失敗した通信 | 赤字でエラー内容ごと残ります |

ツール名が並んでいれば、AIが実際に**学習記録を読み書きしている**証拠になります。失敗が続くときは、その原因(キー・モデル名・通信)がそのまま読めます。

### 20. 英語は「音 → 話す → 読む → 書く → 受験」の5層で積む

英語だけ専用のタブがあります。他の教科と違い、**音と会話という、教科書に無い層**が土台に必要だからです。

#### まず、正直に書きます

> **「会話ができれば、読み書きも受験英語も自然にできるようになる」——これは研究の上では成り立ちません。**
> 読解の精度と英作文の正確さは、別に作らないと身につきません(明示的な文法指導は効果量 **d≈0.96** で、暗示的な学習より明確に大きい — Norris & Ortega 2000)。

**ただし順番には意味があります。** 音と会話を先に作ると、そのあとの読み書きの伸び方が変わります。理由は3つとも「仕組み」の話です。

| なぜ音が先か | 何が起きているか |
|---|---|
| ① **音で区別できない語は、記憶に残らない** | 新しい単語は、まず**音のかたち**として保持されてから長期記憶に移ります。音韻的短期記憶は語彙習得の最も強い予測因子のひとつ(Baddeley, Gathercole & Papagno 1998)。**発音練習は、単語を覚えるための練習**でもあります |
| ② **黙読も、頭の中では音に変換されている** | 音があいまいな語ばかりの文章は、読む速度が落ちます |
| ③ **話すと、足りないものが見つかる** | 聞いているだけでは気づけない穴が、言おうとした瞬間に出ます。会話は練習であり**診断**です |

そのうえで、読解・英作文・受験英語は**5つの層すべてを別々に**持っています。

| 層 | ねらい | やること |
|---|---|---|
| 🔊 **1. 音をつくる** | 日本語にない音を聞き分けられる・出せる | 聞き分けドリル / お手本と聞き比べ / 音読 |
| 💬 **2. 話す** | まちがえてもいいから言い切れる | AIと英会話 / 4-3-2 / 言えなかったことの回収 |
| 📖 **3. 読む** | 戻り読みせずに前から意味を取る | チャンク読み / つなぎ言葉 / 設問タイプ別 |
| ✍️ **4. 書く** | 減点されない英語にする | 和文和訳→英訳 / 自由英作文の型 |
| 🎓 **5. 受験に仕上げる** | 時間内に確実に点にする | 時間配分 / 設問の型 ※**高1まで表示しません** |

いまどの層に重心があるかは、習得済みの英語概念・発音の正答率・単語数・会話回数から自動で判定します。

#### 発音 — 日本語に「無い区別」だけをやる

全部の音をやる必要はありません。問題になるのは日本語に無い区別だけです。**10個**に絞りました。

R/L ・ th ・ F/V と H/B ・ si と shi ・ 母音を足さない ・ 強く言う場所 ・ 弱形と連結 ・ a の3つの音 ・ 長短の i ・ ん の使い分け

各項目に、**なぜ日本語話者がそうなるのか**と、**口・舌・歯のどこが当たるか**を書いてあります。

> ⚠️ **カタカナは一切使いません。** カタカナは間違った音を固定してしまいます。AIにもプロンプトで禁じています。

```
R … 舌をどこにもつけない。舌先を少し奥に引いて、口を軽くすぼめる
L … 舌先を上の前歯のうしろにしっかりつけたまま声を出す
→ 迷ったら「つける/つけない」だけで判断する
```

**練習は3段構えで、端末によって自動で切り替わります。**

| | 何をするか | 使える端末 |
|---|---|---|
| 👂 **聞き分け** | right / light のどちらかが流れる。どっちだったか当てる | **すべて**(読み上げのみ) |
| 🎙 **聞き比べ** | お手本を聞く → 自分の声を録音 → 並べて聞く | iOS 14.3以降・Android・PC |
| 🎤 **通じるか試す** | 音声認識に言ってみて、正しく認識されるか見る | 対応端末のみ |

> 💡 **中心を「聞き分け」に置いたのは意図的です。** 音声認識に頼ると、認識できない端末では発音練習そのものが成立しません。しかも**聞き分けの訓練は、発音そのものも良くする**ことが確認されています(Bradlow et al. 1997 — 日本語話者のR/L訓練)。読み上げの声は**毎回わざと変えます**(高変動音声訓練)。

**通じなかったとき、原因の音を自動で当てます。** right と言って light と認識されたなら、それは R/L の問題です。ミニマルペアの表から逆引きして、その場で口の形を出します。

#### 会話 — 直す時間と、直さない時間を分ける

話している最中に文法を直されると、**話す量そのものが激減します**。流暢さと正確さは同時に伸ばせないので、時間で分けました。

- **会話中は直しません。** どうしても必要なときは**正しい形で言い直して返すだけ**(リキャスト)
  - 沙和「I go to zoo yesterday.」→ AI「Oh, you **went to the** zoo yesterday! What did you see?」
  - 「間違いだよ」とは言いません
- **直すのは会話が終わったあと、2〜3点だけ。** 全部は言いません
- 英語で詰まったら日本語に切り替えてよい。**黙らせるより、言えたほうがいい**

お題は8つ、学年に応じて難易度が付きます。**4-3-2法**(同じ話を2分→90秒→60秒でくり返す)も入れてあります。内容が同じなので考える負担がなく、回を追うごとに口が動くようになります。

#### 語彙 — 単語帳を丸ごと積まない

**これは設計上の判断です。** 3000語を並べて覚えるのは、文章の中で出会って覚えるより定着が弱く、しかも飽きます。そこで積むのは3種類だけにしました。

| | 何を | なぜ |
|---|---|---|
| (a) **不規則動詞**(約75) | 絶対に要るのに**有限** | 型でまとめると覚える量が減る。lie/lay・rise/raise のひっかけ付き |
| (b) **接辞と語根**(37) | 語彙を**何倍にもふくらませる道具** | 語をひとつずつ覚えるより速いことがある |
| (c) **日本語話者だけの罠** | 和製英語(22)・多義語(22) | そのまま言うと通じないか、別の意味になる |

**これ以外の語は積みません。** 実際に読んだ文・解いた問題で出会った語を、AIがその場で登録して**FSRS(忘れかけたころに出す仕組み)**に乗せます。例文つきでしか登録できないようにしてあります。

**「何語知っていれば読めるのか」も正直に出します。**

```
1,000語 → 約72%  会話の基本。文章はまだ読めない
2,000語 → 約80%  5語に1語わからない。辞書なしでは苦しい
3,000語 → 約90%  だいたい追える。細部は落ちる
5,000語 → 約95%  共通テストが読める
8,000語 → 約98%  辞書なしで読める ← ここが目標
```

辞書なしで理解するには**その文章の98%の語**を知っている必要があります(Hu & Nation 2000)。95%では理解度が大きく落ちます。**「わからない単語が20語に1語」でも、まだ足りません。**

#### 文法 — 日本語話者【固有】のつまずきだけを狙う

冠詞・可算不可算・自動詞他動詞・時制。これらは**母語に無い区別**なので、放っておいても直りません。しかも英語圏向けの教材には載っていません。**ここが最短距離です。12項目**を名指しで潰します。

```
✕ I have dog.              →  ○ I have a dog.
✕ discuss about it          →  ○ discuss it
✕ I have been to Kyoto last year.  →  ○ I went to Kyoto last year.
✕ I don't know where does he live. →  ○ I don't know where he lives.
✕ I think he will not come. →  ○ I don't think he will come.
```

各項目に**「なぜ日本語だとそうなってしまうのか」**を必ず付けています。理由が分かると同じ間違いが減りますが、ルールだけでは減りません。習得度も横に出るので、どこが残っているか一目で分かります。

#### 読む・書く

- **長文が読めない最大の原因は「後置修飾」です。** 日本語は修飾語が前にしか来ませんが、英語は名詞の**後ろ**から長い説明がつきます。`The dog / running in the park / is mine.` と区切らせます
- **訳させません。**戻り読みもさせません。つなぎ言葉(however / therefore / for example)を先に囲ませると、読む前に流れが見えます
- 設問タイプ別の解き方7種(主旨・指示語・言い換え・理由・空所補充・図表・不要文削除)
- 英作文は**いきなり英訳させません**。まず**和文和訳** —「彼は口が堅い」→「彼は秘密を人に言わない」→ `He doesn't tell others' secrets.` 難しい単語を探して止まるのを防ぎます
- 減点方式なので、**難しい構文で1つ間違えるより、簡単な文で正確に**書くほうが点は高くなります。見直しは4点だけ(三単現のs / 冠詞 / 単複 / 時制)

#### 受験 — ただし中学生には見せません

**共通テストはリーディング100点・リスニング100点。**以前のセンター試験は筆記200点・リスニング50点でした。リスニングは全体の5分の1から**半分**になっています。音をおろそかにすると、それだけで半分を失います。**発音の練習は、受験でもいちばん割のいい投資です。**

ただしこのタブは**高1以降にしか出しません**。中1・中2には受験の話をしないという原則(#6)は、英語でも同じです。AIにも「中学生には『入試に出る』と言わない」とプロンプトで課しています。代わりに「これが言えると、動物の動画が字幕なしで分かるようになる」のように、いま届く場所を見せます。

## エックスサーバーに置く

**結論:使えます。むしろ GitHub Pages よりこちらを推奨します。**
理由は、エックスサーバーには**アクセス制限(Basic認証)**があり、家族以外がURLにたどり着いても開けないようにできるからです。
このアプリはビルド不要の静的ファイル(HTML / CSS / JS / PNG)だけなので、**アップロードするだけで動きます**。PHPもデータベースも使いません。

### 手順

**1. ファイルをアップロード**

サーバーパネルの「**ファイル管理**」(またはFTP/SFTP)で、`公開したいドメイン/public_html/` の下に、リポジトリの中身を**そのまま**置きます。

```
public_html/
├── index.html   share.html   manifest.json   sw.js   robots.txt
├── css/style.css
├── js/*.js
├── api/backup.php   ← 自動バックアップ用(置くだけ)
└── icons/*.png
```

`docs/` `README.md` は無くても動きます。**サブディレクトリ配置でも動作確認済み**です(`public_html/sawa/` など)。

> 💡 **設定ファイル(`.htaccess`)は同梱していません。** 以前は同梱していましたが、更新のたびに上書きすると
> エックスサーバーの「アクセス制限」(パスワード)が外れてしまうためです。
> **何度上書きしても、パスワード設定は影響を受けません。**
> 細かく設定したい方向けに `docs/htaccess-見本.txt` を置いてあります(任意)。

**2. HTTPSで開けることを確認**

初期ドメイン(`○○.xsrv.jp`)は最初からHTTPSに対応しています。独自ドメインの場合はサーバーパネル →「SSL設定」→「独自SSL設定追加」(無料)。

> ⚠️ **HTTPSは必須です。** HTTPのままだと、オフライン起動・iOSの共有シート・「ホーム画面に追加」が動きません。
> 誤って `http://` で開いた場合は、**アプリ側で自動的に `https://` へ切り替えます**。

**3. アクセス制限(Basic認証)をかける**

サーバーパネル →「アクセス制限」→ 対象フォルダを ON → ユーザーIDとパスワードを設定。家族だけが開ける状態になります。**アプリを更新しても、この設定は消えません。**

**4. iPhoneでホーム画面に追加**

iPhoneの **Safari** でURLを開く → 共有ボタン → 「ホーム画面に追加」。
※ Chrome や LINE内ブラウザからは追加できません。

### 検索エンジン対策について

家族専用なので、三重にふさいでいます。

- `robots.txt`(ドメイン直下に置いたときのみ有効)
- 各HTMLの `<meta name="robots" content="noindex,nofollow,noarchive">` — **どこに置いても効きます**
- サーバーパネルの**アクセス制限(パスワード)** — これがいちばん確実です

### 更新のしかた

[Code] → [Download ZIP] で落として、`public_html` に**そのまま上書き**するだけです。**気をつけるファイルはありません。**

上げたあと、「保護者」タブ →「バージョン」で**2つの版が揃っていれば完了**です。揃っていなければ「最新のファイルを読み込み直す」を押してください(学習記録は消えません)。

自分でファイルを直したときは、`sw.js` の `CACHE` と `js/app.js` の `APP_VERSION` の**両方**を上げてください。

### 料金・容量

スタンダードプランで十分です。全ファイル合わせて **1MB未満**、アクセスも家族数人なので、転送量・容量ともに問題になりません。

> 💡 **サーバー代とは別に、Claude APIの従量課金がかかります**(コンソールで月額上限を設定できます)。
