# 🩺 沙和ナビ — 獣医への6年計画

中学1年から大学受験まで、6年間伴走するAI学習システム。
世界の学習科学の研究を検証し、**効果が確認されている手法だけ**で組み立てています。

## ふつうの学習アプリと違うところ

### 1. つまずきの「本当の原因」を過去にさかのぼって特定する

一次関数ができないとき、多くのアプリは一次関数を教え直します。
このシステムは違います。中1〜高3の**全教科210概念を前提関係のグラフ(DAG)**で保持し、土台をさかのぼります。

```
一次関数 (中2) が解けない
   ↑ が土台
比例 (中1) — 習得30%
   ↑ が土台
一次式の計算 (中1) — 習得55%
   ↑ が土台
正負の数の乗除 (中1) — 習得20%  ← 🚨 本当の原因はここ
```

原因を直してから戻ると、上の単元が一気に通ります。優秀な家庭教師がやることを、システムとして実装しました。

### 2. 「わかったつもり」を最優先の弱点として扱う

答える前に**必ず確信度を申告**させます(◎自信ある / ○たぶん / △わからない)。
確信度 × 正誤で4象限に分け、**「自信あり×不正解」を最優先**にします。

| | 正解 | 不正解 |
|---|---|---|
| **自信あり** | ✅ 定着 | 🚨 **わかったつもり(最優先)** |
| **自信なし** | 🌱 自信不足 | 📘 未習得 |

逆説的ですが、**自信を持って間違えた場所こそ最も強く・長く修正されます**(ハイパーコレクション効果)。
ただし研究では「1週間後に誤りが復活する」ことも判明しているため、**訂正した直後に再出題し、さらに12時間後の再テストを強制的に予約**します。

「わかったつもり率」として数字でも可視化します。この数字が高いほど、本番で崩れやすい状態です。

### 3. わざと混ぜて出題し、その理由を本人に説明する

問題は必ず単元をまたいで混ぜます(交互練習)。研究ではテスト成績が約2倍になります。
**ただし練習中の正答率は 89% → 60% に下がります。**「できていない感じ」がするので、多くの生徒はここでやめてしまいます。

そこでこのアプリは、**「今わざと混ぜている。今日できないのは設計どおり」と本人に明示**し、
「練習中の正答率」と「定着度」を別メーターで表示して混同を防ぎます。
保護者レポートにも同じ説明を載せ、正答率の低さで叱られないようにしています。

### 4. 3つの人格 — 先生・友だち・伴走者

自己決定理論の3つの欲求(有能感・関係性・自律性)にそれぞれ対応させています。状況に応じて自動で切り替わります。

| | 役割 | 支える欲求 | やること |
|---|---|---|---|
| 🐰 **ミミ先生** | 先生 | 有能感 | 答えを言わず導く。確信度を聞き、前提をさかのぼる |
| 🐕 **コタロー** | 友だち | 関係性 | 評価しない。**沙和さんが教える側に回る**(プロテジェ効果) |
| 🦉 **ナギ** | 伴走者 | 自律性 | 計画・振り返り・テスト不安。**必ず選択肢を出し、本人が決める** |

「しんどい」と打てばコタローに、「計画を立てたい」と打てばナギに自動で切り替わります。

### 5. ポイントで釣らない

外的報酬は、報酬がなくなった瞬間にやる気を以前より下げます(過正当化効果)。
そのためXP・バッジ・レベルを主軸から外し、代わりに**「どの概念が本当にできるようになったか」と「夢との距離」**を表示します。

### 6. 成績を入力すると、次にどこへ時間を使うべきか出る

- **定期テスト**:点数と平均点から相対的な立ち位置と推定偏差値を算出
- **内申点**:9教科×5段階=45点(2021年度からの3観点評価に対応)
- **模試偏差値**:獣医学部**全17校**との距離を自動計算
- **限界効用分析**:習得度の穴・テストの得点・獣医学部での重要度を合成し、**同じ1時間を投じて最も合格可能性が上がる教科**を順位づけ

### 7. 保護者には「監視」ではなく「声のかけ方」を渡す

研究では、統制的な関わり(命令・監視・比較)は意欲を確実に下げ、自律性支援(理由の説明・気持ちの承認・選択肢)は成績と心理的健康の両方を高めます。
保護者画面は週次レポートに加えて、**具体的に言ってよい言葉/避けたい言葉**を提示します。

## セットアップ(おうちの方・約10分)

### 1. Claude APIキーを取得

1. [console.anthropic.com](https://console.anthropic.com/) でアカウント作成
2. 支払い方法を登録(従量課金)
3. 「API Keys」→「Create Key」で `sk-ant-api03-…` をコピー

> 💰 **料金の目安**:1回のやりとりで数円〜十数円程度。コンソールの「Limits」で月額上限を設定できます。

### 2. アプリを開く

**方法A:そのまま開く** — [Code] → [Download ZIP] で展開し、`index.html` をブラウザで開くだけ。

**方法B:GitHub Pages(スマホで使うならこちら)**
1. Settings → Pages → Source を `Deploy from a branch`、Branch を `main` / `(root)`
2. 数分後の URL にスマホからアクセスし、ホーム画面に追加

> ⚠️ **リポジトリは Private(非公開)を推奨します。** APIキー自体はページに含まれず端末内にのみ保存されますが、URLを知る人は誰でもページを開けるためです。

### 3. アプリ内で設定

初回は「保護者」タブが開きます。APIキー・名前・学年を入力して保存してください。

## プライバシー

- 学習記録・成績・会話はすべて**この端末のブラウザ内(localStorage)にのみ保存**されます。外部サーバーには保存されません
- APIキーも端末内のみ
- 質問と写真は回答生成のため Anthropic の API に送信されます([プライバシーポリシー](https://www.anthropic.com/legal/privacy))
- 「保護者」タブからJSONで書き出し/読み込みができます。**機種変更の前には必ず書き出してください**

## 構成

```
index.html
css/style.css
js/
  evidence.js     研究の根拠データ(アプリ内で保護者に開示)
  curriculum.js   知識の系譜グラフ — 中1〜高3 全教科210概念のDAG
  memory.js       FSRS記憶モデル・確信度4象限・前提遡行診断
  exam.js         獣医学部17校・成績評価・内申点・限界効用分析
  personas.js     3人格のプロンプトとAI用ツール定義
  api.js          Claude API(ツール実行ループつき)
  app.js          画面制御
docs/EVIDENCE.md  出典つき研究リスト
```

- ビルド不要・サーバー不要の静的サイト
- [Claude API](https://platform.claude.com/)(`claude-opus-5`)をブラウザから直接呼び出し
- **AIはツールを通じて学習データを実際に更新します**(単なるチャットボットではなく、知識モデルを保守するエージェント):
  `record_answer` / `diagnose_prerequisite` / `get_study_queue` / `get_status` / `set_goal`
- 写真は端末内で長辺1568pxに縮小してから送信(通信量とコストの節約)
- プロンプトキャッシュでAPIコストを削減

## 注意

- 偏差値・共通テスト得点率は**目安**です。出願判断は必ず河合塾・駿台等の最新資料でご確認ください
- AIの説明が常に正しいとは限りません。重要な内容は教科書や先生で確認してください
